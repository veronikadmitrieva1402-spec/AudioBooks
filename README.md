# Сервис учета коллекции аудиокниг

## Назначение

Проект предназначен для удобного ведения учета аудиокниг:
1. Добавление новых записей
2. Хранение информации о жанрах и авторах
3. Отслеживание прогресса прослушивания
4. Получение информации о длительности

## Целевая аудитория

Пользователи, которые слушают книги в разных сервисах и хотят их собрать в одном месте.

## Описание предметной области

Учет и каталогизация аудиокниг.
Пользователю важно хранить сведения о книге (название, автор, жанр), также сведения об издании и личный статус.

## Основные сущности

1. Сведения о книге (название, автор, жанр, год, описание)
2. Автор (список произведений, ФИО)
3. Чтец (список озвученных книг, ФИО)
4. Профиль пользователя
5. Запись коллекции (статус, оценка)

## Основные функции

1. Регистрация и авторизация пользователя
2. Добавление, редактирование и удаление аудиокниг
3. Проверка корректности скорости прослушивания
4. Форматирование длительности в вид "Х ч. Y мин."
5. Расчет количетсва дней
6. Поиск и фильтрация по названию, автору, жанру и статусу
7. Проставление оценки
8. Добавление комментариев к книге

## План развития проекта

1. Проектирование базы данных
2. Добавление простого веб-интерфейса
3. Авторизация и личный кабинет
4. Поиск с фильтрацией
5. Статусы и оценки
6. Адаптивный дизайн

## Веб-интерфейс (Django)

### Запуск веб-версии
python manage.py runserver
После запуска открой в браузере: http://127.0.0.1:8000/

### Страницы проекта
- `/` — Главная страница (описание проекта и навигация);
- `/books/` — Список аудиокниг из базы (JSON);
- `/books/<id>/` — Карточка конкретной аудиокниги;
- `/users/` — Список пользователей.

### Структура Django-проекта
- `roomly/` - настройки проекта и главная маршрутизация;
- `homepage/` - приложение главной страницы и общий HTML-каркас (Bootstrap);
- `audiobooks/` - приложение для работы со списком книг;
- `users/` - приложение для работы с пользователями.
- `templates/` - глобальные шаблоны (base.html, навигация)
- `static/` - статистические данные (CSS, JS, img)

### Django Template Language

- Базовый шаблон base.html содержит общую структуру страницы и блоки {% block title %} и {% block content %}.
- Наследование реализовано через {% extends "base.html" %} во всех дочерних страницах.
- Включаемые шаблоны (навигация, карточки книг) подключаются через {% include %}.
- Циклы {% for book in books %} используются для вывода списков, условия {% if book.is_finished %}.
- Фильтры шаблонов: количество (|length) и значение по умолчанию (|default).
- Именованные URL: все ссылки формируются через {% url %}, а не жёстко прописаны в HTML.

### Статические файлы
- Cобственный CSS (style.css)
- Собственный JavaScript (main.js) автоматически подставляет текущий год в футере.
- В шапке используется изображение (logo.png).
