# Сервис учета коллекции аудиокниг

## Назначение

Проект предназначен для удобного ведения учета аудиокниг:
1. Добавление новых записей
2. Хранение информации о жанрах и авторах
3. Отслеживание прогресса прослушивания
4. Получение информации о длительности пользования

## Целевая аудитория

Пользователи, которые слушают книги в разных сервисах и хотят их собрать в одном месте.

## Описание предметной области

Учет и каталогизация аудиокниг. 
Пользователю важно хранить сведения о книге (название, автор, жанр), также сведения об издании и личный статус. 

## Основные сущности 

1. Сведения о книге (название, автор, жанр, год, описание)
2. Автор (список произведений, ФИО)
3. Чтец (список озвученных книг, ФИО)
4. Профиль пользователя
5. Запись коллекции (статус, оценка)

## Основные функции 

1. Регистрация и авторизация пользователя
2. Добавление, редактирование и удаление аудиокниг
3. Поиск и фильтрация по названию, автору, жанру и статусу
4. Проставление оценки
5. Добавление комментариев к книге
6. Отображение обложек

## План развития проекта 

1. Проектирование базы данных 
2. Добавление простого веб-интерфейса
3. Авторизация и личный кабинет
4. Поиск с фильтрацией
5. Статусы и оценки
6. Адаптивный дизайн
7. Валидация
